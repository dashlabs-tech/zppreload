# ZPP Reload Website
Website statis. Deploy: GitHub → Settings → Pages → branch `main` / root.
- Kontak, deposit, form, analytics: `assets/js/main.js` (bagian CFG)
- Harga: buka `admin.html`, konversi TSV, upload `data/harga.json`
- Banner pengumuman: `data/pengumuman.json` (atau lewat admin.html)
- Domain: file `CNAME` dibuat otomatis GitHub saat Custom domain diisi
